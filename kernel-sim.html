INTER-SUBSYSTEM SIMULATION FLOW

Demonstrates the exact 5-step OS interaction chain from the lab manual: Process creation → Scheduling → I/O → Completion → File read. Click Run Full Simulation to watch all subsystems interact in sequence.

1
PROCESS CREATION
Process Manager creates PCB → Memory Manager allocates RAM → Ready Queue enqueues process
2
SCHEDULER DISPATCH
Scheduler dequeues process → transitions state to Running → starts execution timer
3
I/O FILE WRITE → WAITING STATE
Process issues file write → transitions to WAITING → File System allocates inode + data blocks → I/O completes → back to READY
4
PROCESS TERMINATION
Scheduler marks process TERMINATED → Memory Manager frees allocated RAM blocks
5
FILE READ REQUEST
File System reads data blocks → returns content → inode access logged
