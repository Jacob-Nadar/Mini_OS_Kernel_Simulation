# 🖥️ Mini OS Kernel Simulator

An interactive browser-based OS kernel simulation built with pure HTML, CSS & JavaScript.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## Features
- ⚙️ **Process Manager** — Create processes, track full state lifecycle (New → Ready → Running → Waiting → Terminated)
- ◈ **CPU Scheduler** — Round Robin & Priority Preemptive with configurable time quantum
- 📋 **Queue Management** — Live Ready Queue & I/O Waiting Queue visualization
- 🧠 **Memory Manager** — First Fit allocation across 1024MB with fragmentation tracking
- 📁 **Virtual File System** — Create, Write, Read, Delete with inode tracking
- 📋 **Kernel Event Logger** — Real-time timestamped log with export support

## Run Locally
No installation needed — just open in browser:
```bash
git clone https://github.com/yourusername/mini-os-kernel-simulator.git
open kernel-sim.html
```

`HTML5` · `CSS3` · `Vanilla JavaScript` · `Chart.js` · `GSAP`
